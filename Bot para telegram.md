Un bot de Telegram para inventario de una tienda de repuestos ("VCH Repuestos") que permite:

Gestión de inventario: buscar, agregar, editar y eliminar repuestos con código, nombre, categoría, stock y precio
Control de usuarios: admin + usuarios, con botones diferenciados por rol
Módulo de ventas: busca el repuesto → cantidad → precio (con descuento/recargo) → carrito multi-artículo → descuenta stock automáticamente
Historial de cambios: cada edición de stock/repuesto queda registrada (campo, valor anterior→nuevo, usuario)
Reportes: resumen de ventas y cambios, filtros por mes/año, export a Excel desde Telegram
Proforma en PDF con logo (vía /setlogo)
Backup automático diario
